Core 3 tickets
DT-001M
App shell & sidebar navigation
Layout foundation that all views are built inside.
  • Svelte app wrapper — fixed sidebar (224px) + scrollable main area
  • Nav items with icons, hover states, and orange active indicator bar
  • Client-side view routing — nav click swaps view without page reload
  • Sidebar user row at bottom with avatar initials and role label
DT-002S
Topbar component
Persistent header that contextualises the active view.
  • Page title syncs with active nav item on route change
  • Live indicator pill with pulsing animated dot
  • Real-time clock display, updates every second
  • Named slot for contextual action buttons (e.g. "+ Nouveau trajet")
DT-024M
DataTable — composant table réutilisable
Composant unique partagé par toutes les vues liste. Doit être construit avant DT-006, DT-011, DT-014, DT-018, DT-022.
  • Props : endpoint, columns (key + label + render?), filters (chips), searchParam, paginated, limit
  • Mode paginated: false — charge tout en une requête (Flotte ~200, Employés ~250)
  • Mode paginated: true — pagination curseur avec params after + limit, contrôles next/prev, réinitialise le curseur à chaque changement de filtre (Trajets, Documents, Maintenances)
  • Callback render(val, row) par colonne pour injecter badges, pills d'expiration, formatage — le composant ne connaît pas le domaine
  • États gérés en interne : loading skeleton, erreur, liste vide — slots nommés pour les personnaliser
Dashboard 3 tickets
DT-003S
KPI stats cards
Four headline numbers that summarise the operation at a glance.
  • API endpoint returning fleet, trip, liter, and billing aggregates
  • Cards: camions actifs, trajets en cours, litres livrés (mois), facturation HT (mois)
  • Sub-text breakdown per card (e.g. "4 en route · 2 prêts · 1 maintenance")
DT-004M
Fleet status lanes widget
Compact fleet overview on the dashboard — not the full fleet table.
  • One row per truck: plate, animated progress bar, status badge, route info
  • Three visual states: En route (moving node), Maintenance (hatching), Prêt (idle node)
  • "Voir tout" button navigates to Flotte view
  • Reuses fleet API payload — no second request
DT-005S
Recent trips table widget
Last 6 trips shown read-only on the dashboard.
  • Columns: N° trajet, Camion, Route, Chauffeur, Quantité, Statut, Date
  • Status badges: En cours, Terminé
  • "Voir tout" link navigates to Trajets view
Flotte 5 tickets
DT-006M
Fleet list table
Main fleet view — one row per truck, clickable for detail.
  • API endpoint: GET /trucks (plate, model, tanker, capacity, status, last oil change)
  • Columns: Immatriculation, Modèle, Citerne, Statut, Dernière vidange
  • Row hover highlight; cursor pointer to signal clickability
  • Overflow-x: auto container for wide screens
DT-007M
Document expiry tracking columns
Four document columns per truck with color-coded expiry pills.
  • Store 4 expiry dates per truck: Ass. camion, Ass. produit, Visite tech., Permis ch.
  • Days-remaining computed server-side; pill color: green (>60j) / yellow (15–60j) / red (<15j or expired)
  • API endpoints to create and update expiry dates
DT-008S
Fleet filters & search
Status chips and a search bar to narrow 150+ trucks quickly.
  • Filter chips: Tous / En route / Prêts / Maintenance — client-side row filtering
  • Search input filters by plate number or model in real time
  • Active chip and search term persist across drawer open/close
DT-009M
Truck detail drawer
Slide-in panel with full truck context, opened by clicking any row.
  • Sections: tanker + last oil change summary, driver card (name / ID / phone), 4 document rows with expiry, 3 stats boxes (trips / km / litres)
  • Populated from fleet list payload — no extra request on open
  • Closes on overlay click or Escape key
DT-010M
Add truck form
Drawer to register a new truck and its associated documents.
  • Fields: plate, model, year, tanker ID, capacity, last oil change date
  • Four document expiry date pickers
  • Driver assignment dropdown filtered to Chauffeur employees
  • API POST /trucks; new row appended to fleet table on success

Employee list table
Full employee directory with operational info visible at a glance.
  • API endpoint: GET /employees (name, emp ID, role, phone, address, hire date, status, assigned truck)

DT-012S
Employee filters & search
Same filter + search pattern as the fleet view.
  • Filter chips: Tous / Chauffeurs / Techniciens / Admin
  • Real-time search by name or employee ID
  • Count in "Tous" chip updates to reflect filtered results
DT-013M
Add / edit employee form
Drawer to onboard or update an employee record.
  • Fields: full name, role (select), phone, address, hire date, status
  • Truck assignment field shown only when role = Chauffeur
  • API POST /employees and PUT /employees/:id
Trajets 4 tickets
DT-014M
Trip list table
Full trip history with status filtering.
  • API endpoint: GET /trips with optional status filter
  • Columns: N° trajet, Camion/Citerne, Route, Chauffeur, Gasoil (L), Essence (L), Montant HT, Statut, Départ
  • Filter chips: Tous / En cours / Planifiés / Terminés / Annulés
DT-015L
New trip drawer
4-section form to plan a convoy and generate a delivery note.
  • Section 01 Convoi — truck select with auto-populated tanker and pairing card
  • Section 02 Itinéraire — origin, destination, departure + arrival date/time; route rate shown on selection
  • Section 03 Chauffeur — optional assignment with "habituel" hint for regular driver
  • Section 04 Bon de livraison — reference number + fuel quantities (gasoil / essence)
  • API POST /trips; closes drawer and refreshes trip list on success
DT-016S
Tank fill visualizer
Live capacity bar inside the trip form, segmented by fuel type.
  • Segmented bar (gasoil + essence) filling against the selected tanker's capacity
  • States: empty prompt, partial warning (X L remaining), exact fill confirmation, over-capacity error
  • Reads capacity reactively from the selected truck field
DT-017S
Estimated billing in trip form
Live billing preview computed from liters × route rate.
  • Computes HT = total liters × route rate per liter
  • Displays TVA 18% and total TTC inline
  • Updates reactively on any quantity or route change; hidden when inputs are incomplete

Card-based log of maintenance sessions, ongoing and completed.

Monthly billing summaries with payment status at a glance.

One-click generation of a billing draft from completed trips.
